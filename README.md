☕ Cafe Management System

A simple Cafe Management System built using Python and MySQL.
The project provides a menu-driven interface to manage cafe records directly from a MySQL database. 🍰💻

 ✨ Features

* 🍽️ Manage menu items
* 🧑‍🤝‍🧑 Manage customers
* 👨‍🍳 Manage staff and chefs
* 🪑 Manage tables and seating
* 🧾 Manage orders
* 💰 Manage bills and payments
* 📦 Manage inventory and stock
* 🚚 Manage suppliers
* 🔗 Manage relationships between tables
* 🔍 Search records
* ➕ Insert records
* ✏️ Update records
* 🗑️ Delete records
* 👀 View table data
* 💻 Run custom SQL `SELECT` queries

 🛠️ Technologies Used

* 🐍 Python
* 🐬 MySQL
* 🔌 MySQL Connector/Python
